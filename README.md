# おくすりメダル＋ v1.5

服薬記録とメダルアーケードを統合したWebアプリです。

## 主要フロー
1. NFCタグまたは一覧から薬を選択
2. 服薬後、空になった袋・シートを撮影
3. GASへ画像を送信して服薬記録
4. メダル +1
5. 月〜日が7日そろった日曜日にメダルアーケードを解放
6. メダルを使ってミニゲームをプレイ

## v1.5 の主な変更
- アプリ名称を「おくすりメダル＋」へ統一
- 新しいロゴをTOPへ正式採用
- キャラクターを使わない新しいアプリアイコンを採用
- PWA用 `manifest.webmanifest`、各種ホーム画面アイコン、faviconを追加
- Service Workerを追加し、アプリ本体とミニゲームの静的ファイルをキャッシュ
- ローディング、TOP、設定、アーケード内ヘッダーのブランド表記を統一
- オフライン時の通信警告表示を追加
- NFC URLコピー時のモーダルalertをやめ、非侵襲的なトースト表示へ変更
- スマホ幅でロゴ・日付・タグラインが崩れにくいレイアウトへ調整
- 開発用UIレビューHTMLは本番パッケージから除外

## 報酬ルール
- 服薬写真の送信が完了するたび、メダル +1
- その日の服薬記録日を日付単位で保存
- 保護者がチェックした曜日のうち、当日を含む直近7日間がすべて記録済みの日にアーケードをプレイ可能
- ゲーム1回につき原則メダル1枚
- 通常ミニゲームはゲームごとの条件達成でメダル獲得あり
- ブロックパズル／スライドランはメダル消費のみ
- 未使用メダルは削除されず、次の解放日まで保持

## Windows / VS Code でローカル確認
このフォルダでPowerShellを開き、以下を実行します。

```powershell
python -m http.server 5500
```

Chromeで `http://localhost:5500` を開きます。

## ミニゲーム追加
`games/README_ADD_GAME.md` を参照してください。基本は1ゲーム1フォルダを追加し、`games/manifest.js` に1項目追加するだけです。

## PWA
- `manifest.webmanifest` を追加済み
- iOS用 `apple-touch-icon.png` を同梱
- Android/Chrome向け192px / 512px / maskable iconを同梱
- Service Worker `sw.js` を同梱

## 既知の通信上の注意
服薬画像POSTは元アプリと同じく `mode: no-cors` を使用しています。そのため、ブラウザ側ではGASのレスポンス本文を確認できず、「GAS側で保存まで完了したこと」を厳密には検証できません。フロントエンド側の完成版ではこのサーバー仕様は変更していません。


## v1.5 保護者設定
- ゲームの日を月〜日のチェックボックスから複数選択できます。初期値は日曜日のみです。
- チェックした曜日のうち、当日を含む直近7日間がすべて記録済みのときアーケードが開きます。
- 「おうちのかた用設定」は4桁PINで保護されます。初回にPINを作成し、以後はPIN認証が必要です。
- PINを5回間違えると1分間だけ入力をロックします。PINは端末内にハッシュ化して保存します。


## v1.6 ゲーム日の複数選択
- 保護者設定で月〜日のチェックボックスから複数曜日を選択できます。
- 初期値は日曜日のみです。旧 `gameDay` 設定は自動的に `gameDays` へ引き継ぎます。
- 選択した曜日のうち、直近7日間（当日を含む）すべてに服薬記録がある日にアーケードが開きます。
- 例：火曜・土曜を選択し、服薬が毎日続いていれば火曜と土曜の両方で遊べます。
- ゲーム日の変更は従来どおり保護者PINで保護されます。
