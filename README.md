# おくすりメダル＋ v1.8

服薬記録とメダルアーケードを統合したWebアプリです。

## 主要フロー
1. NFCタグまたは一覧から薬を選択
2. 服薬後、空になった袋・シートを撮影
3. GASへ画像を送信して服薬記録
4. メダル +1
5. 保護者が選んだ曜日にメダルアーケードを解放
6. メダルを使ってミニゲームをプレイ

## v1.5 の主な変更
- アプリ名称を「おくすりメダル＋」へ統一
- 新しいロゴをTOPへ正式採用
- キャラクターを使わない新しいアプリアイコンを採用
- PWA用 `manifest.webmanifest`、各種ホーム画面アイコン、faviconを追加
- Service Workerを追加し、アプリ本体とミニゲームの静的ファイルをキャッシュ
- ローディング、TOP、設定、アーケード内ヘッダーのブランド表記を統一
- オフライン時の通信警告表示を追加
- NFC URLコピー時のモーダルalertをやめ、非侵襲的なトースト表示へ変更
- スマホ幅でロゴ・日付・タグラインが崩れにくいレイアウトへ調整
- 開発用UIレビューHTMLは本番パッケージから除外

## 報酬ルール
- 服薬写真の送信が完了するたび、メダル +1
- その日の服薬記録日を日付単位で保存
- 保護者がチェックした曜日はアーケードをプレイ可能
- ゲーム1回につき原則メダル1枚
- 通常ミニゲームはゲームごとの条件達成でメダル獲得あり
- ブロックパズル／スライドランはメダル消費のみ
- 未使用メダルは削除されず、次の解放日まで保持

## 既知の通信上の注意
服薬画像POSTは元アプリと同じく `mode: no-cors` を使用しています。そのため、ブラウザ側ではGASのレスポンス本文を確認できず、「GAS側で保存まで完了したこと」を厳密には検証できません。フロントエンド側の完成版ではこのサーバー仕様は変更していません。


## v1.5 保護者設定
- ゲームの日を月〜日のチェックボックスから複数選択できます。初期値は日曜日のみです。
- チェックした曜日はアーケードが開きます。
- 「おうちのかた用設定」は4桁PINで保護されます。初回にPINを作成し、以後はPIN認証が必要です。
- PINを5回間違えると1分間だけ入力をロックします。PINは端末内にハッシュ化して保存します。


## v1.6 ゲーム日の複数選択
- 保護者設定で月〜日のチェックボックスから複数曜日を選択できます。
- 初期値は日曜日のみです。旧 `gameDay` 設定は自動的に `gameDays` へ引き継ぎます。
- 選択した曜日はアーケードが開きます。7日間の記録は継続を見える化するために表示します。
- 例：火曜・土曜を選択すると、火曜と土曜の両方でアーケードが開きます。プレイには服薬でためたメダルが必要です。
- ゲーム日の変更は従来どおり保護者PINで保護されます。


## v1.7 今日の服薬記録の修正
- PIN認証後の「おうちのかた用設定」に「今日の服薬記録を修正」を追加しました。
- 今日の記録がある薬だけを一覧表示し、1回単位で取り消せます。
- 取り消すと、その薬の端末内の今日の記録回数を1回減らします。
- 未使用メダルが残っている場合は1枚減らします。すでに使ったメダルを負数にはしません。
- 今日の端末内記録が0件になった場合は、今日の7日間記録も未達成へ戻します。
- 誤操作の確認用として、直近50件まで端末内に訂正ログを保存します。
- **重要:** この操作は端末内データの修正です。GASへすでに送信したGoogle Driveの写真、スプレッドシートの服薬記録行は自動削除しません。必要な場合は保護者がDrive／スプレッドシート側で確認・削除してください。


## v1.8 ゲーム日の解放ルール修正・見える化
- 保護者設定でチェックした曜日は、その曜日になればアーケードをOPENにします。
- 7日間すべての服薬記録をOPEN条件にはしません。服薬記録は継続の見える化として残します。
- プレイには従来どおりメダルが必要です。メダルは服薬記録で獲得します。
- 7日間の記録では、ゲーム日に「★」とゴールド系の強調を表示します。
- 10本すべてのミニゲーム内のLOCK判定も同じルールへ統一しました。
