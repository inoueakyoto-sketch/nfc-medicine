# ブロックパズル v0.2

## 目的
自己ベストを更新し続けるエンドレス型パズル。勝敗・時間制限なし。

## ルール
- 8×8盤面
- 毎回3つのブロックを提示
- 好きな順番で配置
- 縦または横1列が埋まると消去
- 3つ使い切ると次の3つを配る
- 残っているどのブロックも置けなくなったら終了

## 得点
- 置いた1マス: 10点
- 1ライン消去: 100点を基礎にボーナス
- 複数ライン同時消去: 追加ボーナス
- 連続してラインを消す: COMBO倍率（最大6倍）

## メダル
- 開始時に1枚消費
- ゲーム中・終了時とも獲得なし
- 自己ベストは localStorage `medicine-medal-block-puzzle-best-v1` に保存

## 操作
- ブロックをタップ → 盤面をタップ
- またはブロックをドラッグ → 盤面で離す

## v0.2 操作修正
- 短いタップは「選択」、一定距離以上の移動で「ドラッグ」に切り替える。
- タップ配置とドラッグ配置は同じ基準点で計算する。
- ドラッグ中は半透明のブロック表示と盤面プレビューで置き位置を示す。
